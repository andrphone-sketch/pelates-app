# Εφαρμογή Πελατών για Μηχανικό (Android / PWA)

Αρχείο πελατών & έργων που τρέχει στο κινητό σου σαν εγκατεστημένη εφαρμογή.
Τα δεδομένα αποθηκεύονται ΤΟΠΙΚΑ στο τηλέφωνο (localStorage) — δεν ανεβαίνουν πουθενά.

## Τι περιέχει
- Καταχώρηση πελάτη/έργου (στοιχεία ιδιοκτήτη, ακίνητο, υπηρεσία, αμοιβές, πληρωμή).
- Αναζήτηση + φίλτρα ανά υπηρεσία και κατάσταση.
- Στατιστικά (σύνολο πελατών, ενεργά, αμοιβές, εισπραχθέν, υπόλοιπο, ανεξόφλητα).
- Εξαγωγή CSV (συμβατό με το αντίστοιχο Excel) και Backup JSON.
- Εισαγωγή CSV (ενσωμώνει εγγραφές από το Excel ή άλλη συσκευή).

## Πώς την εγκαθιστάς στο Android
1. Ανέβασε τον φάκελο `App` (index.html + manifest.webmanifest) σε έναν δωρεάν φιλοξενητή, π.χ.:
   - **GitHub Pages** (αποθετήριο public → Settings → Pages), ή
   - **Netlify Drop** (https://app.netlify.com/drop — σύρεις τον φάκελο, έτοιμο σε δευτερόλεπτα).
2. Άνοιξε το URL από το **Chrome** του τηλεφώνου.
3. Πατάς ⋮ → **«Προσθήκη στην Αρχική οθόνη»**. Τώρα έχεις εικονίδιο σαν native app.

> Αν δεν θες φιλοξενία, μπορείς απλά να ανοίγεις το `index.html` μέσα από έναν file manager /
> browser στο κινητό (π.χ. μεταφέροντας τον φάκελο μέσω USB). Η εφαρμογή δουλεύει κανονικά,
> απλώς δεν «εγκαθίσταται» ως εικονίδιο.

## Sync με το Excel
- Από την εφαρμογή: **⬇ Εξαγωγή CSV** → το ανοίγεις στο Excel και αντιγράφεις τις γραμμές
  στο φύλλο «Πελάτες-Έργα» (τα ποσά και οι ημερομηνίες μεταφέρονται έτοιμα).
- Από το Excel: επιλέγεις τις γραμμές → Αντιγραφή → Επικόλληση σε ένα κενό CSV ή χρησιμοποιείς
  το **⬆ Εισαγωγή CSV** της εφαρμογής.

## Σημείωση ασφαλείας
Τα δεδομένα μένουν στη συσκευή. Κάνε τακτικά **💾 Backup (JSON)** και φύλαξέ το σε υπολογιστή/cloud,
γιατί αν σβήσεις τα δεδομένα του browser ή αλλάξεις συσκευή, χάνονται.

# Κροκί Τοπογραφικού (PWA)

Φάκελος `topo-survey/` — εφαρμογή για την **κατασκευή κροκιού επί τόπου** με το GPS του κινητού.

## Τι κάνει
- Συλλογή **σημείων**, **γραμμών** και **πολυγώνων** πάνω στον χάρτη (tap ή με το τρέχον GPS).
- Φωτογράφηση κάθε στοιχείου (με την κάμερα) + κωδικός/κατηγορία/σημείωση.
- **Μετατροπή WGS84 → ΕΓΣΑ87** αυτόματα (επίσημο σύστημα για οικοδομικές άδειες), ώστε να εισάγεις
  τις συντεταγμένες απευθείας στο AutoCAD / Civil 3D.
- **Offline-first**: η εφαρμογή (κώδικας + βιβλιοθήκες) αποθηκεύεται στο τηλέφωνο μέσω Service Worker.
  Μόνο οι χάρτες χρειάζονται σύνδεση (προφόρτωσέ τους στο εργαστήριο). Τα δεδομένα μένουν τοπικά (IndexedDB).
- Εξαγωγές: **CSV (ΕΓΣΑ87)**, **KML** (Google Earth), **GeoJSON**.

## Εγκατάσταση στο Android
Ίδια διαδικασία με την εφαρμογή πελατών: ανέβασε τον φάκελο `topo-survey/` σε GitHub Pages/Netlify,
άνοιξε το URL στο Chrome και **「Προσθήκη στην Αρχική οθόνη」**.

## Σημείωση ακρίβειας
Το GPS του κινητού χωρίς εξωτερικό δέκτη έχει απόκλιση **±3–5 m**. Για εκατοστά, σύνδεσε εξωτερικό
GNSS δέκτη (π.χ. Emlid Reach) μέσω Bluetooth. Η εφαρμογή καταγράφει τα raw lat/lon που δίνει το τηλέφωνο.
